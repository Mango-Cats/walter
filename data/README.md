# walter/_data

There are three important datasets in this folder:

    - `R_ph.csv`: contains a preprocessed Philippine registered human
    drugs. This data is freely available online. The original dataset
    is stored in `_data/raw/drug_products.csv` which was saved by
    Erin Chua on December 16, 2026.

    ` `R_us.csv`: contains a preprocessed United States registered
    human drugs. This data is freely available online. The original
    dataset is stored in `_data/raw/Products.txt` which was saved by
    Zhean Ganituen on May 9, 2026.

    - `P_us.csv`: contains a preprocessed version of ISMP's List of Confused Drug Names as a CSV file.
