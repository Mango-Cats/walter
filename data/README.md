# walter/data

There are two important datasets in this folder:

    - `drug_products.csv`: contains Philippine registered-human
    drugs. This data is freely available online.

    - `ismp.csv`: ISMP's List of Confused Drug Names as a CSV file
    with parentheticals removed and text normalized. This isn't used
    anywhere in the project but is kept here for bookkeeping.

This folder is also where walter stores the preprocessed or cleaned
(drug_products.csv) dataset.
